权重空间编程与模型能力研究

  • Sparks of Weight-Space Programming：LLM 可直接读写神经网络权重 — 论文（Takehi、Teoh、Alex Zhang、Omar Khattab）称 GPT-6 Astra 仅看原始权重的浮点数文本就能判断网络的功能并修改它；AINews 把它放在 Karpathy 八个月前 autoresearch 的脉络里解读，认为它绕过了"写 PyTorch、跑集群、看 loss 曲线"的流程。 原文
  • Qwen 3.8 27B 在笔记本上也能解释模型权重 — Simon Willison 复现了论文中的一个例子，本地 27B 模型同样能解读权重，说明该能力不限于前沿模型。 原文
  • Import AI 479：Realtime-Bench 显示 LLM 在低延迟任务上很差 — 50 个动态任务，30 个 web 任务（旅行、电商、服务、安全四类）+20 个游戏任务（街机、解谜、策略、模拟），考察延迟动作直接影响成败的场景；由 UT Austin、俄亥俄州立、UIUC、NVIDIA、西北大学等合作构建。本期另含 Spacewar、Genie 4。 原文

Agent 产品、API 与路由

  • Perplexity 推出 teammates — 面向长期运行工作的个人 agent，能规划协调项目、随优先级变化调整并提交结果供审阅；建立在 Computer 之上，此前让 agent 承担持续性工作需要手工规划。 原文
  • Perplexity Computer 面向电商 — 连接 Shopify（店铺数据与落地页）、Meta（广告）、Klaviyo（邮件营销），可用 skills 存放品牌设计规范，用于搭产品页和投放广告/邮件活动。 原文
  • Agent API 各档 effort 全面降价并新增 ultra — 每个档位单次查询成本下降，研究质量持平或提升；effort 是打包配置（模型、步数预算、搜索设置、工具），按名称调用（如 effort="fast"）自动套用新配置。 原文
  • Decisions API 支持 web grounding — 请求中加 "mode": "web_grounding"，每个问题跑一次 Perplexity Fast Search，结果作为证据写入 state；state 也可直接给 URL 指向特定页面。基准为 PWS-Decisions。 原文
  • OpenRouter 新一代 Auto Router / Auto Code Router — 底层重建，按基准最多比旧路由高 4×，路由步骤快 3×；可在 chatroom 查看路由决策理由，在模型页看实时路由分布。 原文
  • OpenRouter Guardrails 拆分组织限制与工作区默认值 — 预算、模型访问、内容审核成为三类独立策略，组织级设上限、工作区可设默认并做例外；向后兼容。背景数据：10 人以上团队用户一年增长 70 倍，平均组织的活跃 API key 数是过去的 3 倍。 原文
  • Tavily 上线 Composio Instant — 支持 web search 与内容提取，无需单独注册 Tavily 账号、管理 API key 或订阅，按调用从 Composio 钱包计费。 原文
  • PI v1.5.0 — 新增扩展包更新 changelog 展示（可配置路径、collapseChangelog 折叠）、大工具调用增量解析与高亮复用以提升流式渲染、自定义自更新命令（PI_SELF_UPDATE_COMMAND/selfUpdateCommand）；接入 GPT-6.1 Terra（OpenAI、Azure OpenAI Responses、OpenAI Codex，Codex 提供 500K 上下文，支持 tool search、对话中途切换 thinking 级别及关闭 thinking）。破坏性变更：工具参数校验行为调整。 原文

Agent 与网站之间的身份、访问与安全

  • Cloudflare：Agent 不是人类（但又有点像） — 论证站点需要身份、声誉、问责三项机制才能在 Agent 代人访问时保留站点与用户的关系；Agent 可能看起来像普通用户，也可能是一个访客携带多个用户。 原文
  • Cloudflare 上线个人 Agent 的分析与访问策略 — 新增 analytics 让站点看清哪些个人 agent 在访问、做了什么，并提供更细粒度的访问控制，替代"一刀切屏蔽"。 原文
  • Cloudflare Zero Wire：关键漏洞情报中心 — 公开的漏洞情报 feed，面向需要快速判断"我们是否受影响"的安全团队；文中指 AI 正在提高严重漏洞被发现的数量与速度。 原文
  • Privacy Pass 的后量子化 — 除 TLS 外，Privacy Pass 这类用于限速、替代 CAPTCHA 与指纹识别的隐私协议同样依赖易受量子攻击的密码学，文章讨论其迁移方案。 原文

网页数据与检索基准（Firecrawl）

  • Legal Retrieval Benchmark 发布 — 581 条法律检索请求，用于评测搜索 API，每条要求返回一份官方文档（法规、条例、判决或机构指引），全部来自 Firecrawl 政府与法律索引的真实客户查询；与索引改进构成每周循环。 原文
  • 法律数据 API 横评：CourtListener、PACER 等 — CourtListener 免费账号 125 请求/天，LegiScan 免费层 1 万查询/月，PACER 按页计费 $0.10，2027 年 1 月 1 日起涨至 $0.12，Westlaw 与 Lexis 的 API 需走销售。 原文
  • 面向 AI 购物 agent 的商品数据 API：5 家对比 — Bright Data、Apify、Oxylabs、Zyte 按站点 scraper/Actor 或 AI 抽取售卖、按每千条记录计价，Firecrawl 为第五个选项；核心论点是模型训练数据没有当前价格，需返回价格、促销价、变体、库存、图片、评论等结构化字段。 原文
  • B2B 开发客户的 5 步流程与 AI prompt — 定义理想客户、列出匹配账户、找到采购决策者、检查购买信号、写出相关的首句；强调融资、招聘、职位每月变动，需实时数据。 原文

评测、可观测性与开发工具

  • Braintrust 支持追踪 MCP server — 可看到 agent 请求了什么、工具调用返回了什么，用 Patterns 聚合发现问题；针对"工具返回成功但 agent 拿错数据或理解错"的情况，服务端错误日志不够用。 原文
  • Arize Phoenix 自动更新模型价格 — 价格目录不再绑定版本发布，服务器可在版本之间接收新费率；在 Settings > Models 可查看当前内置价格目录的日期。 原文
  • Vercel Security Review 公测 — Vercel Agent 的第三项能力（另两项为 Code Review 和 Investigation），GitHub push（含直推生产分支）触发扫描改动代码，查找缺失鉴权、泄露密钥等问题；结果出现在 PR 评论、Security dashboard 和 CLI，授权后 Agent 可验证并推送修复；monorepo 中按项目根目录限定范围。 原文

Vercel 客户案例

  • Zapier — 用 v0 在两小时内做出交互式合作伙伴 demo（原流程需数周），三个内部应用各一天出首版，为 60 多名营销人员建共享日报，单月创建 330 万个 sandbox 隔离 AI 工作负载的代码执行。 原文
  • Mercor — 批处理任务从 12 小时压到 2 小时；10 天内经 AI Gateway 路由 1800 万请求、630 亿 token；用 Vercel Passport 秒级开通专家访问；内部构建者创建了 2000 多个项目。 原文
  • OpenEvidence — 为 65 万名医生提供带引用的医学检索；生产部署约 5 分钟完成，用 Fluid compute 将 serverless 支出降低 90%，流量尖峰无需额外扩容。 原文

系统与基础设施工程

  • Meta F3 Lightning：广告 ML 特征上线提速 — F3 把单请求 2 万多个特征编译进一张合并图以降低计算成本，但该图同时是发布单元，单个特征失败或定义非法就阻塞整条发布流水线；F3 Lightning 在其上加一层，让每个特征独立编译、校验、部署和回滚，难点是保持原有效率——早期按特征发布的原型因特征不再共享计算而推高了 CPU 使用。 原文
  • Anthropic 重新设计源码控制 — 编码本身已不是瓶颈（Claude 能跑研究循环、优化程序、从零建服务），瓶颈转移到围绕写代码的基础设施。 原文
  • Netflix 用 AI agent 做性能工程 — 介绍其在分布式架构中压缩响应时间、定位 CPU/内存瓶颈、控制基础设施成本的 agent 实践。 原文
  • Nvidia Nemotron 模型家族的工作方式 — 拆解其核心设计思路：在保持模型容量的同时压低推理开销。 原文
  • LLM 推理系统是怎么跑的 — 以一次请求为线索讲三个核心难题：每步都要访问巨大模型时如何快速出 token、如何在 GPU 显存与容量有限时服务多用户、如何既快又不浪费昂贵硬件。 原文
