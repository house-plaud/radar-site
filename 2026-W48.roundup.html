  • Rex 为何先做 Windows 客户端而非 Linux — Windows 开发者数量超过其他桌面 OS 总和；Linux/FreeBSD 服务端即将公开发布，客户端稍后；Linux 桌面因意见多样而更难。 原文

  • DoorDash 派单系统重构 — 应对持续变化环境中的派单决策，解决容量划分与创新扩展两大问题。 原文

  • ByteByteGo：数据库行的生命周期 — 插入/更新/删除涉及内存、WAL、索引、多版本、后台清理、复制等；已提交行可能尚未落盘，删除行可能继续占空间。 原文
  • Composio 推出 BYOC — 允许客户在自己的云中运行凭据和数据处理；配套 Firewall 控制 agent 可执行动作。 原文
