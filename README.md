# radar 周报

一份自动生成的技术资讯周报，分两章：**AI 工程**（agent 的 harness、编排、评测、
推理成本）和**系统设计**（架构、规模化、分布式）。

**→ [在线阅读](https://house-plaud.github.io/radar-site/)**

---

## 它是什么

每周一期，三个部分：

| 部分 | 内容 |
|---|---|
| **值得读的** | 按阅读预算精选十条上下，逐条压缩成几句话 |
| **社区在聊什么** | 榜单类来源（HN / Reddit / Trending）整批压成综述，不逐条列 |
| **还没细看的** | 主题匹配但未进精选的，给核心观点与数据，供有余力时判断是否细读 |
| **论文** | arXiv 与 Hugging Face Daily Papers，只取**应用侧**（agent 怎么组织工作，不是模型怎么跑） |

## 两条设计原则

**一期一份，过期即归档。** 不做未读数、不做待读列表 —— 会涨的数字就是负债，
而负债会让人把整个列表标记成噪声。这期不看就过期了，天然不堆积。

**宁缺毋滥。** 不追求覆盖全，追求读完的那几条真的有用。漏掉可以接受，
把注意力花在噪声上不可接受。

## 这个仓库

只存渲染好的 HTML。生成它的代码、订阅源清单和原始语料都在另一个私有仓库里 ——
这样「什么被公开了」没有模糊空间。页面带 `noindex`，不进搜索引擎。
